# Javid EasyLoad Pro — Android APK build

This project uses Capacitor 7. The Android APK is built by GitHub Actions.

## Build the APK
1. Upload/commit all files in this folder to the root of your GitHub repository (the `main` branch).
2. Open the repository on GitHub.
3. Open the **Actions** tab.
4. Select **Build Android APK**.
5. Press **Run workflow** (or wait for the build after pushing to `main`).
6. When the run is complete, open it and download the artifact named **Javid-EasyLoad-Pro-APK**.
7. Extract the artifact ZIP; inside is `app-debug.apk`. Install it on your Android phone.

The debug APK is for testing and direct installation. Keep a separate backup of your shop data.
